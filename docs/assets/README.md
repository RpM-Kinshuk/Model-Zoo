# README visual system

Every figure in the root README is generated by one script from this
repository's own measurements. Each figure exists twice, `<name>-dark.svg` and
`<name>-light.svg`, and the README shows the one that matches the reader's
GitHub theme through `<picture>` with a `prefers-color-scheme` source. The SVGs
are self-contained: no scripts, no external fonts or images, CSS motion only.

| Figure | What it shows | Data |
| --- | --- | --- |
| `hero` | The wordmark, three defining formulas and a ridgeline of eigenvalue densities, one ridge per weight matrix, tails colored by fitted α | All 50 measured matrices of `EleutherAI/pythia-160m` |
| `measure` | The four outputs of a run: weights, spectra, fingerprints, zoo | One pythia-160m histogram; the phase-2 catalog for the zoo card |
| `terminal` | The quick start as a typed terminal session | The README's commands |
| `architecture` | Runner, dispatcher, isolated workers, package; supervision rail and the confirmed-cleanup loop | Schematic |
| `gpus` | Parallelism across models (worker processes with their own GPUs) and within a model (layer threads) | Schematic |
| `lifecycle` | Load, analyze, finalize under monitoring; cleanup order; the three signals | Schematic |
| `spectrum` | One spectrum in full: histogram, λ<sub>min</sub>, λ<sub>max</sub>, tail fit on log-log axes, α by depth | `gpt_neox.layers.5.mlp.dense_h_to_4h` of pythia-160m |
| `fingerprint` | Row block, two-sided sketch `S = L B Rᵀ`, block hash, sketch cosine, lineage tiers | Schematic |
| `zoo` | The measured models placed by median α and stable rank, with declared parents; the seven snapshot tables and queries | `analysis_runs/phase2/catalog.csv`; query results from the 2026-11-02 Zoo-Keeper smoke |
| `footer` | One measured density with its tail | The same pythia-160m layer |
| `glyph-*` | Navigation and heading icons, mid-tone strokes that read on both themes | None |

Numbers in data panels come from the tracked runs and are never typed in by
hand. Matrix tiles in the schematic figures are seeded low-rank patterns that
show shape, not values. The Marchenko–Pastur curve in `spectrum` is a visual
reference for an i.i.d. matrix of the same shape and norm; the pipeline does
not compute it.

## Regenerate

```bash
python -m pip install fonttools brotli        # once, beside numpy, pandas and h5py
python docs/assets/src/figures.py             # every figure and glyph
python docs/assets/src/figures.py --only zoo  # one figure, both themes
```

| Path | Role |
| --- | --- |
| `src/figures.py` | One function per figure; data loading from `analysis_runs/phase2` |
| `src/svgkit.py` | Theme tokens, text measurement, shapes, comets, font subsetting and embedding |
| `src/fonts/` | Renamed subsets of Instrument Serif, DM Mono, STIX Two Text and STIX Two Math, under the [SIL Open Font License](src/fonts/OFL.txt) |
| `src/icons/` | Hugging Face, PyTorch and NVIDIA marks from [gilbarbara/logos](https://github.com/gilbarbara/logos) (CC0); the names and logos are trademarks of their owners |

Each figure embeds only the glyphs it uses, as base64 WOFF2, because an SVG
shown through `<img>` cannot load fonts. Text widths come from the font
metrics, so layouts do not depend on the reader's installed fonts.

## Rules

- **Two themes from one code path.** Colors come from the `THEMES` tokens in
  `svgkit.py`; never hard-code a hex value in a figure. Colored text uses the
  `_t` variants, which keep contrast on both backgrounds.
- **Resting state first.** Every animated element's base style is its final,
  readable state, and an in-SVG `prefers-reduced-motion` rule stops all motion.
  A paused or reduced-motion figure must carry its full meaning.
- **Motion shows flow, not telemetry.** Comets follow real edges, outlines
  light in reading order, the typing loop replays the quick start. Nothing
  implies live progress, speed or capacity.
- **Keyframes use fixed values.** Per-element timing comes from `--d` and `--t`,
  read outside `@keyframes`.
- **No captions under figures.** The section heading names the figure; the
  `alt` text carries its full description. Update the README's `alt` text
  whenever a figure's content changes.
- **Native text stays native.** Commands, flags, defaults and links live in
  Markdown, outside collapsed sections for the quick start; figures summarize.
- **Keep the anchors.** `top`, `quick-start`, `start-a-run`, `install`,
  `what-a-run-writes`, `architecture`, `gpu-allocation-and-parallelism`,
  `runtime-controls-and-cache-lifecycle`, `measurement-scope`,
  `evidence-and-zoo`, `the-zoo`, `oversized-models` and
  `verification-and-maintenance` are linked from other documents.

## Palette

The palette follows a 60–30–10 balance: a neutral ink or vellum ground, cool
structure (blue, sea green, green) and warm light (gold, rose) as the
complementary accent. Violet appears only as an accent. Each pipeline stage keeps
one hue everywhere: I gold, II rose, III sea green, IV blue.

| Token | Dark | Light | Role |
| --- | --- | --- | --- |
| `panel` | `#0a0f16` | `#fbf8f1` | Figure ground, under nebulae and stars |
| `ink` | `#f5f1e8` | `#16213a` | Primary text |
| `gold` | `#ffc457` | `#cf8f12` | Tails with 2 ≤ α < 4, motion, stage I |
| `ember` | `#ff6f8e` | `#d9466f` | Tails with α < 2, λ<sub>max</sub>, stage II |
| `teal` | `#3fdcc8` | `#0e9c8f` | Marchenko–Pastur, the CPU sidecar, stage III |
| `blue` | `#6aa8ff` | `#2f6fdc` | The bulk of a spectrum, GPU threads, stage IV |
| `green` | `#8be08f` | `#2b9a52` | Confirmed cleanup, the second worker |
| `violet` | `#b48cff` | `#7a4ddb` | Tails with α ≥ 4 |
| `neb1`–`neb4` | sea green, peach, blue, lilac | the same, paler | Nebula washes |

Instrument Serif sets titles and roman numerals, STIX Two Text sets labels
and captions, DM Mono sets identifiers and commands, and STIX Two Math sets
mathematics. The hero's ridges shade from blue to green with depth; their tails carry the warm α colors.

## Check before committing

Preview each changed figure in both themes at 1012 px, GitHub's README width,
and at about 830 px; check overlaps, arrowheads and text contrast. Freeze a few
animation times and the reduced-motion state. Keep each SVG near or under 100 KB.
